My work investigates how machine-learning systems can analyse complex physiological, movement, and security data while remaining interpretable, privacy-aware, and suitable for responsible human oversight. ## Current research

### Explainable multimodal gait analysis for telerehabilitation

A pre-clinical machine-learning framework combining **EEG, EMG, IMU, and force-plate data** for gait-speed and BMI classification.

- 51-participant harmonised cohort
- Deterministic five-fold subject-wise cross-validation
- Unimodal and multimodal fusion experiments
- Logistic regression, RBF-SVM, random forest, XGBoost, and 1D-CNN
- PCA, PLS, ANOVA, and mRMR feature strategies
- Random-forest SHAP analysis for model interpretation
- Training-fold-only preprocessing to reduce information leakage

[View the research repository →](https://github.com/siamabdurrahman/Gait-assessment-and-telerehabilitation)

### Privacy-preserving IoT security and guarded AI remediation

An independent research framework connecting:

- Explainable IoT threat detection
- Privacy and data-governance controls
- Human-in-the-loop decision support
- Guardrailed LLM-assisted remediation
- Verification, rollback, escalation, and auditable logging

This work explores how AI-assisted security operations can remain accountable and safe rather than relying on unrestricted automated action.
